Cadastrar Aluno

Sobre o site

O Cadastro de Alunos é um sistema simples para registrar informações de estudantes. Você preenche o formulário com nome, idade, curso, e-mail e cidade e acompanha os dados na própria tela, antes de salvar.

Como funciona

1

Preencha

Informe os dados do aluno no formulário.

2

Confira

Veja os dados do aluno na tela enquanto digita.

3

Salve

Clique em Salvar para registrar o cadastro.
